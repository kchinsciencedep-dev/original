Science Department staff area

For the admin and school management. Each link opens a Google Sheet, and only people who have been given access to that sheet can open it.

Sign in with the Google account that has been given access. If a sheet says you need permission, ask the sheet's owner to share it with you.

  • Science teachers

    Admin can edit

    Add a row to add a new science teacher, or delete a row to remove one. In the Subject column write Biology, Chemistry, Physics or Other. When the sheet is connected to the school website, the team list on the website follows this sheet.

    Open the teachers sheet

  • Apparatus breakages

    Private: admin and management only

    Add a row each time a student breaks apparatus, with the date, name, class, item and details. Change Status to Resolved when it is settled, or delete the row to remove the record. This sheet is not shown on the school website.

    Open the breakages sheet

  • Materials for upcoming practicals

    Admin edits, management views

    The admin adds a row for each upcoming practical with the date, subject, class, materials and quantity. Management can open the sheet at any time to see what must be ready.

    Open the materials sheet

Who can see what

  1. Open a sheet, click Share at the top right, and add a person's Google email address.
  2. Give the admin Editor access so they can add and remove rows.
  3. Give management Viewer access so they can read the sheet but not change it.
  4. Keep General access set to Restricted so that only the people you add can open it.
